# Feature Specification: 资金统计标签页

**Feature Branch**: `016-fund-statistics`  
**Created**: 2026-05-09  
**Status**: Draft  
**Input**: User description: "资金管理增加资金统计标签页，放在第一个，包括：显示当前账户余额、当前持仓金额；饼图显示当前账户余额、当前持仓金额；折线图展示过去60个月每月的账户余额和持仓金额"

## Clarifications

### Session 2026-05-09

- Q: 数据自动更新策略 → A: 页面进入时加载数据，无需刷新
- Q: 饼图交互需求 → A: 鼠标悬停时显示tooltip
- Q: 折线图数据点密度 → A: 每月一个数据点，共最多60个点

- Q: 错误提示的具体形式 → A: 使用现有的Modal组件显示错误信息

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 查看资金概览统计 (Priority: P1)

用户能够在资金管理页面的第一个标签页"资金统计"中查看当前的资金概况，包括当前账户余额和当前持仓金额的数值显示，以及一个饼图直观展示两者在总资产中的占比关系。

**Why this priority**: 这是资金统计的核心功能，为用户提供即时的资金状况总览，是用户进入资金管理页面后首先关注的信息。

**Independent Test**: 可以通过验证页面是否正确显示当前账户余额（来自transfer_records表最后一条记录）和当前持仓金额（来自各持股的最新市值），以及饼图是否正确反映两者的比例关系来独立测试此功能。

**Acceptance Scenarios**:

1. **Given** 用户打开资金管理页面并选择"资金统计"标签（默认第一个标签）, **When** 页面加载完成, **Then** 显示当前账户余额和当前持仓金额的数值卡片，账户余额从transfer_records表最后一条记录的account_balance字段获取，持仓金额通过以下步骤计算：从trade_records表获取当前所有持仓股票及数量（直接使用holdingCount字段），从kline_data表查询各持股最新收盘价，然后计算 Σ(收盘价 × 持仓数量)
2. **Given** 用户已看到资金概览数值, **When** 查看下方的饼图, **Then** 饼图正确显示账户余额和持仓金额在总资产（账户余额+持仓金额）中的占比，使用不同颜色区分两个部分，并显示具体数值和百分比
3.用户能够通过折线图查看过去60个月（5年）的账户余额、持仓金额和总资产的变化趋势，了解资金的长期变化情况。图表支持鼠标悬停查看具体月份的详细数据。
“暂无数据”提示
4. **Given** 用户在资金统计页面, **When** 账户余额或持仓数据发生变化（如新增转账记录、交易记录或股价变动）, **Then** 用户可以点击刷新按钮重新加载最新数据

### User Story 2 - 查看历史资金趋势 (Priority: P2)

用户能够通过折线图查看过去60个月（5年）的账户余额和持仓金额变化趋势，了解资金的长期变化情况。图表支持鼠标悬停查看具体月份的详细数据。

**Why this priority**: 历史趋势分析帮助用户理解资金的长期变化模式，识别投资收益的时间分布，但依赖于基础数据的完整性。

**Independent Test**: 在有足够月份的资金明细和持仓数据的情况下，验证折线图是否正确显示过去60个月的数据点，每条线代表一个指标（账户余额/持仓金额），并支持交互查看详细信息。

**Acceptance Scenarios**:

1. **Given** 用户打开资金统计页面, **When** 页面加载完成, **Then** 在饼图下方显示一个折线图，横轴为月份（过去60个月，格式为"YYYY-MM"），纵轴为金额，包含三条折线分别表示账户余额、持仓金额和总资产的变化趋势
2. **Given** 用户有过去60个月的资金明细记录和交易记录, **When** 查看折线图, **Then** 系统按月度聚合数据，每月末的账户余额取该月最后一天或之前最近一条transfer_records记录的account_balance，每月末的持仓市值通过以下步骤计算：从trade_records表获取该月末时点的所有持仓股票及数量（取该日期之前最近一条记录的holdingCount字段值），从kline_data表查询各持股在该月末日期（或之前最近交易日）的收盘价，然后计算 Σ(收盘价 × 持仓数量)
3. **Given** 用户将鼠标悬停在折线图的某个数据点上, **When** 悬停在该点上方, **Then** 显示tooltip提示框，包含该月份的日期、账户余额、持仓金额和总资产（账户余额+持仓金额）
4. **Given** 某些月份没有资金明细记录或K线数据, **When** 查看折线图, **Then** 对于缺失的月份，系统使用该月之前最近一个有数据的月份的值进行填充，或者在完全没有数据时该月份不显示数据点
5. **Given** 用户的历史数据不足60个月, **When** 查看折线图, **Then** 图表仅显示实际存在的月份数据，从第一条记录开始到当前月份

---

### Edge Cases

- 当数据库中没有任何资金明细记录时，账户余额显示为0，持仓金额根据当前持股计算（从trade_records表获取持仓数量，从kline_data表获取最新收盘价）
- 当用户没有任何持仓时（trade_records表中没有BUY交易或所有股票已清仓），持仓金额显示为0，饼图仅显示账户余额部分（100%）
- 当过去60个月内某些月份没有transfer_records记录时，使用之前最近一个月的账户余额作为该月的值
- 当某些月份无法获取持股的K线数据时，该月份的持仓市值使用之前最近一个月有K线数据的值，或显示为0
- 当某个月份的trade_records表中没有交易记录时，该月的持仓状态与之前最近一个有交易的月份相同
- 当用户首次使用系统且没有任何历史数据时，折线图显示“暂无历史数据”提示
- 当查询K线数据失败时，系统应显示错误提示并允许用户重试
- 当账户余额或持仓金额为负数时（理论上不应该发生），系统仍正常显示但用特殊颜色标记警告

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 在资金管理页面增加"资金统计"标签页，并将其放置在标签导航的第一个位置，标签页顺序为：资金统计、资金明细、盈亏统计
- **FR-002**: 系统 MUST 在资金统计标签页顶部显示两个数值卡片，分别展示当前账户余额和当前持仓金额
- **FR-002a**: 当前账户余额 MUST 从transfer_records表中获取最后一条记录的account_balance字段值，如果没有记录则默认为0
- **FR-002b**: 当前持仓金额 MUST 通过以下步骤计算得出：
  1. 从交易记录表（trade_records）中获取当前所有持仓股票的代码和持仓数量（直接使用每条记录的holdingCount字段）
  2. 从kline_data表中查询各持股的最新收盘价
  3. 计算公式：持仓金额 = Σ(各持股最新收盘价 × 持仓数量)
  4. 如果没有持仓或无法获取K线数据则显示0
- **FR-003**: 系统 MUST 在数值卡片下方显示一个饼图，直观展示账户余额和持仓金额在总资产中的占比
- **FR-003a**: 饼图 MUST 使用两种不同的颜色区分账户余额和持仓金额，例如账户余额使用蓝色(#3b82f6)，持仓金额使用橙色(#f97316)
- **FR-003b**: 饼图 MUST 在每个扇区上显示对应的数值和百分比，例如"账户余额: ¥10,000 (40%)"
- **FR-003c**: 当账户余额和持仓金额都为零时，饼图 MUST 显示"暂无数据"提示而不是空图表
- **FR-003d**: 系统 MUST 支持鼠标悬停交互，当用户将鼠标悬停在饼图的扇区上时显示tooltip提示框，展示该部分的详细信息
- **FR-004**: 系统 MUST 在饼图下方显示一个折线图，展示过去60个月（包括当月）的账户余额、持仓金额和总资产的变化趋势
- **FR-004a**: 折线图 MUST 包含三条折线，一条表示账户余额（建议使用蓝色#3b82f6），一条表示持仓金额（建议使用橙色#f97316），一条表示总资产（建议使用绿色#10b981）
- **FR-004b**: 折线图的横轴 MUST 显示月份标签（格式为"YYYY-MM"），纵轴显示金额（单位：元），每个月份对应一个数据点，最多显示60个数据点
- **FR-004c**: 每月末的账户余额 MUST 取该月最后一天或之前最近一条transfer_records记录的account_balance值
- **FR-004d**: 每月末的持仓市值 MUST 通过以下步骤计算：
  1. 从交易记录表（trade_records）中获取该月末时点的所有持仓股票及其持仓数量（取该日期之前最近一条记录的holdingCount字段值）
  2. 从kline_data表中查询各持股在该月末日期（或之前最近交易日）的收盘价
  3. 计算公式：持仓市值 = Σ(各持股收盘价 × 该时点的持仓数量)
  4. 如果某只持股在该日期没有K线数据，MUST使用之前最近一个交易日的收盘价
  5. 如果完全没有持仓，则该月持仓市值为0
- **FR-004e**: 当某个月份没有资金明细记录时，该月的账户余额 MUST 使用之前最近一个有记录的月份的值
- **FR-004f**: 当某个月份无法获取持股K线数据时，该月的持仓市值 MUST 使用之前最近一个有K线数据的月份的值
- **FR-004g**: 持仓数量的获取 MUST 直接使用trade_records表中对应记录的holdingCount字段值，无需累计计算
- **FR-005**: 系统 MUST 支持鼠标悬停交互，当用户将鼠标悬停在折线图的数据点上时显示tooltip提示框
- **FR-005a**: Tooltip提示框 MUST 显示该月份的日期、账户余额、持仓金额和总资产（账户余额+持仓金额）
- **FR-006**: 系统 MUST 在页面进入时自动加载最新的资金统计数据，无需提供手动刷新按钮
- **FR-007**: 系统 MUST 在数据加载过程中显示加载状态提示（如loading spinner或"加载中..."文字）
- **FR-008**: 系统 MUST 使用Canvas技术绘制饼图和折线图，与项目中现有的ProfitChart组件保持一致的技术栈
- **FR-009**: 系统 MUST 支持响应式布局，在不同屏幕尺寸下正确显示图表和数值卡片
- **FR-010**: 系统 MUST 在获取数据失败时使用Modal组件显示友好的错误提示，并提供重试选项

### Key Entities *(include if feature involves data)*

- **资金概览(FundOverview)**: 代表当前时刻的资金状况快照，包含以下属性：当前账户余额（来自transfer_records表最后一条记录的account_balance）、当前持仓市值（根据trade_records表的持仓数量和kline_data表的最新收盘价计算得出）、总资产（账户余额+持仓金额）
- **月度资金数据(MonthlyFundData)**: 代表某一个月的资金统计数据，包含：月份（YYYY-MM格式）、月末账户余额（该月最后一天或之前最近一条transfer_records记录的account_balance）、月末持仓市值（根据该月末时点trade_records表的持仓数量和kline_data表对应日期的收盘价计算得出）、月末总资产（账户余额+持仓市值）
- **持仓快照(PositionSnapshot)**: 代表某一时间点的持仓状态，包含：股票代码、股票名称、持仓数量（直接从trade_records表的holdingCount字段获取）、该日期收盘价、个股市值（收盘价×持仓数量）
- **饼图数据项(PieChartDataItem)**: 代表饼图中的一个扇区，包含：标签（"账户余额"或"持仓金额"）、数值（金额）、颜色（十六进制颜色代码）、百分比（占总资产的百分比）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户能够在打开资金统计页面后2秒内看到完整的资金概览数据（账户余额、持仓金额和饼图）
- **SC-002**: 过去60个月的折线图数据能够在3秒内加载并渲染完成
- **SC-003**: 鼠标悬停时tooltip提示框能够在0.3秒内显示
- **SC-004**: 95%的用户能够在一分钟内理解并正确使用资金统计功能查看自己的资金状况
- **SC-005**: 资金统计数据的准确率达到100%，与手动计算的账户余额和持仓市值完全一致
- **SC-006**: 图表在窗口resize后能够在1秒内自适应调整大小并重新渲染
- **SC-007**: 在数据加载失败时，100%的用户能够看到清晰的错误提示并知道如何重试

## Assumptions

- 用户已经熟悉资金管理的基本概念，包括账户余额和持仓市值的含义
- transfer_records表中已经存储了历史资金明细记录，包括每条记录的account_balance字段
- trade_records表中已经存储了所有股票交易记录，包括BUY和SELL类型，每条记录包含holdingCount字段表示该交易后的持仓数量
- kline_data表中存储了各持股的历史K线数据，包括每日收盘价
- 系统采用本地数据库存储所有数据，不需要云端同步功能
- 金额使用人民币(CNY)作为货币单位，显示时使用两位小数
- 用户界面采用中文显示，符合中国用户的使用习惯
- 饼图和折线图的颜色方案遵循项目的整体设计规范，盈利相关使用红色(#ef4444)，账户余额使用蓝色(#3b82f6)，持仓金额使用橙色(#f97316)，总资产使用绿色(#10b981)
- 过去60个月的计算从当前月份往前推算，包括当前月份
- 如果某些月份的数据缺失，系统会使用最近的有效数据进行填充，以保证折线图的连续性
- 持仓数量直接从trade_records表的holdingCount字段获取，无需累计计算
