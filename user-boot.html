StockAnalyzer · 用户操作手册

面向个人投资者的本地化股票分析与持仓管理桌面应用

v0.x · 适用版本：2026-09-20 之后 · 平台：Windows 10 / 11（Electron 桌面应用）

1. 写在前面

1.1 这本手册给谁看

这本手册面向 StockAnalyzer 的最终使用者，也就是日常用这个软件看行情、记交易、跑网格、复盘盈亏的人。它不讲解代码如何实现，只讲"在界面上点什么、点完之后会发生什么"。

1.2 这本手册不包含什么

  • 不包含安装包签名、数据库 Schema、源码组织等开发侧细节（这些见 design.html）。
  • 不包含证券投资建议，所有计算结果仅供参考，不作为买卖依据。
  • 不包含命令行排障路径，如需查看日志请直接使用应用内置的"日志"页面。

1.3 阅读约定

提示 本手册中所有"按钮名称 / 菜单名称 / 输入框标签"均与界面中显示的中文文本完全一致，请按字面查找。
注意 所有"风险"小节都来自真实使用中可能造成数据不一致或资产误判的操作，遇到时务必先停下来读一遍。

1.4 软件定位

StockAnalyzer 是一个本地优先的桌面应用：行情通过行情 API 拉取（可配置），但所有交易记录、持仓、资金明细、K 线、网格策略都保存在本机数据库（sql.js 文件）中，不上传任何第三方服务器。因此：

  • 删除、重装应用不会丢失数据，只要不删除本地数据库文件。
  • 联网时自动刷新行情；断网时仍可读写本地数据，仅实时刷新受影响。
  • 请定期到"设置 → 数据库备份"手动备份一次，避免硬盘损坏导致数据丢失。

2. 安装与启动

2.1 安装

  1. 双击下载到的安装包（StockAnalyzer-Setup-x.y.z.exe），按向导完成安装。安装目录默认为 C:\Users\<用户名>\AppData\Local\Programs\StockAnalyzer\。
  2. 安装完成后，桌面会自动生成"StockAnalyzer"快捷方式。

2.2 首次启动

  1. 双击桌面快捷方式启动应用。第一次启动时，应用会在用户数据目录生成 stockanalyzer.db（SQLite 文件），这步可能耗时数秒。
  2. 启动后默认进入"自选股"页面。如果数据库为空，会看到"暂无自选股 · 添加第一只股票"提示。

2.3 启动参数与托盘

  • 关闭主窗口时，应用默认最小化到系统托盘，不退出进程；右键托盘图标可选择"显示主窗口 / 退出"。
  • 如需彻底关闭进程，请使用托盘菜单的"退出"或任务管理器。
注意 用户数据目录位置：%APPDATA%\StockAnalyzer\（Windows）。数据库文件、日志、备份均在该目录下。不要手动修改 stockanalyzer.db 或日志目录，否则可能导致下次启动失败。

4. 第一次使用（推荐流程）

如果你刚装上 StockAnalyzer，建议按以下顺序走一遍，整个流程不超过 10 分钟：

  1. 进入"设置"，确认"交易时间段 / 轮询间隔 / API 提供商"三块配置（默认即可使用）。
  2. 进入"自选股"，点击"添加股票"，输入股票代码（如 sh600519），名称会自动补全。
  3. 回到自选股列表，点击对应行的"下载K线"按钮，按弹窗选择日期范围和复权方式，下载历史 K 线。
  4. 下载完成后，点击股票名称，打开 K 线图，确认数据已落库。
  5. 进入"资金管理 → 资金明细"，添加一条"转入"记录，建立初始账户余额。
  6. 进入"持仓 → 新增交易"，录入首笔买入记录。系统会自动写入对应的"股票买入"资金流水。
  7. 进入"网格仿真"，输入初始资金、网格上下沿、每档手数，点击"开始仿真"，查看历史回测结果。
建议 完成前 6 步后，应用就具备了"看价格 + 算盈亏 + 跑仿真"的基本闭环。后续每天只需在"持仓"补录交易即可。

5.1 添加自选股

  1. 点击页面右上角"添加股票"按钮。
  2. 在弹窗中填写：
    • 股票代码：6 位数字，前缀决定交易所，sh=沪、sz=深、bj=北、hk=港。例如 sh600519、sz000001、hk00700。
    • 股票名称：输入代码后失焦（或回车），会自动从行情接口拉取名称。如果拉取失败可手动输入。
    • 买入阈值：监控用，可选。当前价 ≤ 买入阈值时会触发系统通知。
    • 卖出阈值：监控用，可选。当前价 ≥ 卖出阈值时会触发系统通知。
  3. 点击"保存"。新股票会出现在列表顶部。
注意 买入阈值必须 < 卖出阈值。如果填反或相等，保存按钮会变灰并提示原因。

5.2 编辑与删除

  • 点击行内"编辑"按钮可修改买卖阈值（代码与名称不允许在编辑模式下修改，如需改名请删除后重新添加）。
  • 点击"删除"会弹出确认框；删除自选股不会删除已产生的交易记录或持仓——已买入的股票即使从自选股列表移除，仍会在"持仓"页面正常显示。

5.3 监控与阈值

  • 每行右侧有一个监控开关（拨片样式）。打开后，主进程按"轮询间隔"持续拉取当前价；价格突破阈值时弹出 Windows 系统通知。
  • 关闭监控开关后只保留"显示"，不产生提醒，但价格仍会随刷新按钮更新。
  • 列表按"监控开关 ↑、更新时间 ↓"排序，被监控的股票永远靠前。

5.4 下载与查看 K 线

5.4.1 下载 K 线

  1. 点击行内"下载K线"按钮，弹出下载对话框。
  2. 选择：
    • 起始日期 / 结束日期（结束日期不能晚于今天）。
    • 复权方式（多选）："不复权"与"前复权"可同时下载，写入不同列。
  3. 点击"开始下载"。下载进度通过 Toast 提示。完成后可在"形态检测"或"K 线图"中查看。
提示 "前复权"会把历史价格按最近一次除权除息回溯调整，看技术形态/趋势更连贯；"不复权"保留真实成交价，适合核对历史交易记录。建议两者都下载。

5.4.2 查看 K 线图

  1. 点击股票名称（不是代码），弹出 K 线弹窗。
  2. 顶部有"复权方式"切换（默认前复权）。
  3. 图表上叠加该股的所有交易记录标记：▲ 买入（红）、▼ 卖出（绿）。鼠标悬停可看到当时的价格、数量、累计持仓。

5.5 手动刷新价格

页面右上角的"刷新按钮"（带循环箭头的图标）：

  • 点击后立即拉取所有自选股的最新价，不受轮询间隔限制。
  • 刷新期间按钮显示"加载中…"，列表显示"最后刷新时间"。
  • 如果行情接口暂时不可达，Toast 提示失败原因，但本地数据不会被清空。

6.1 新增交易

  1. 点击"新增交易"按钮，弹出交易编辑器。
  2. 填写：
    • 股票代码：必须是自选股列表中已有的代码。如果尚未加入自选股，请先去"自选股"添加。
    • 方向：买入 / 卖出。
    • 日期：交易发生当日，不能晚于今天。
    • 价格：单股成交价，最多两位小数。
    • 数量：必须为 100 的整数倍（A 股最小一手 = 100 股）。
    • 手续费（可选）：默认按"佣金率 0.025%、印花税 0.05%（仅卖出）"自动计算，可手动覆盖。

  3. 点击"保存"。系统会：
    • 写入 trade_records 表。
    • 自动同步生成一条资金流水（详见 §6.4）。

6.2 查看持仓

列表按股票分组，每只股票一个卡片：

  • 股票名称 / 代码
  • 持仓数量：所有买入 - 所有卖出，自动算到今天。
  • 成本均价：移动加权平均成本（详见 §附录）。
  • 最新价：从自选股轮询拉取。
  • 浮动盈亏：(最新价 - 成本均价) × 持仓数量。红涨绿跌配色。
  • 收益率：(最新价 - 成本均价) / 成本均价 × 100%。

点击卡片可展开/收起该股所有交易记录（同时只能展开一只，点其他股票会自动收起上一只）。展开后按时间倒序列出全部买入/卖出明细。

6.3 编辑与删除交易

  • 在展开的交易明细上，点击某一条的"编辑"，可修改价格、数量、日期、备注。修改后资金流水会自动反向调整。
  • 点击"删除"会弹确认框；删除会同时同步删除对应的资金流水。
风险 删除交易记录意味着"该笔从未发生过"。如果只是为了平账，请用"反向卖出"交易记录冲销，不要直接删除。

6.4 资金明细自动同步

新增 / 编辑 / 删除交易时，会按以下对照表自动写入资金明细：

交易操作 自动生成的资金流水
买入 STOCK_BUY · 金额 = 买入价 × 数量 + 买入佣金
卖出 STOCK_SELL · 金额 = 卖出价 × 数量 − 卖出佣金 − 印花税
分红（暂未开放 UI） DIVIDEND · 金额 = 每股分红 × 持仓数量
分红税（同上） DIVIDEND_TAX · 按 FIFO 原则扣除

资金流水同步发生在服务层，而不是数据库触发器。这意味着：

  • 同步失败会弹 Toast 警告（黄色）但不会回滚交易——你需要去"资金管理 → 资金明细"手动补录一条。
  • 资金明细列表中由交易自动生成的条目会标注"来源：交易 ID"，不可直接编辑，只能去改对应交易。

操作步骤

  1. 在"选择持仓股票"下拉框中选择一只已持仓股票（系统会自动填充持仓数量与均价）。
  2. 手动填写"总金额"（你愿意分配给这只股票的总资金，含持仓市值 + 现金）与"当前股价"。
  3. 点击"计算"。

结果解读

  • 当前持仓：实际持仓数量、均价、市值。
  • 目标持仓：网格策略下的"目标持仓金额 = 总金额 × 50%"，按当前价折算为股数。
  • 偏差百分比：(当前市值 - 目标市值) / 目标市值 × 100%。
    • 偏差在 ±10% 内 → 无需调整（绿）。
    • 偏差 > +10% → 需要卖出（红）。
    • 偏差 < −10% → 需要买入（红）。
  • 建议数量：调整手数，按 100 股取整。

8.2 开仓计算

用于"首次建仓该买多少"——按"半仓原则"给出建议买入数量。

操作步骤

  1. 填写"总金额"与"开仓股价"。
  2. 点击"计算"。

结果解读

  • 开仓金额：总金额 × 50%。
  • 建议买入数量：开仓金额 / 开仓股价，按 100 股取整。
  • 剩余资金：总金额 × 50%，用于后续加仓。

网格仿真把网格/阈值策略在历史 K 线上跑一遍，输出"假如当时按此策略机械执行"的模拟盈亏。所有写入只发生在内存，不会修改 trade_records、transfer_records。

共五种内置策略：

编号 名称 触发逻辑
策略1 整批清仓 上涨穿越时一次性卖出栈顶批次的全部持仓。
策略2 分步减仓 上涨穿越时，对所有已穿越待减批次各卖出其买入量的一半（分两段减仓）。
策略3 隔两档卖出 与策略 1 类似，但需上穿"高两档"才卖（如 4.2 买入→上穿 4.6 卖出）。
策略4 半仓平衡 不依赖网格，按日收盘做半仓再平衡——目标持仓金额 = 可用资金 / 2，偏差超 ±5% 时按差额动态买卖。
策略5 阈值全仓 不依赖网格，仅用两个触发价做全仓/空仓切换——空仓且收盘价 ≤ 买入触发价则全仓买入；持仓且收盘价 ≥ 卖出触发价则清仓卖出。

9.1.3 费用（可选，带默认值）

  • 最低佣金：默认 5 元/笔。
  • 印花税：默认 0.0005（万分之 5，仅卖出）。
  • 每股分红：默认 0，按持仓数量每日计入分红。

  • 仅保留最近 10 份备份，超出自动删除最旧。
  • 除了手动备份，应用自动在启动时和每日定时各做一次备份。
建议 每次进行大量录入（批量补录历史交易、批量下载 K 线）之前，手动备份一次，万一录入出错可恢复。

14. 日志查看

日志页面是只读的滚动日志查看器，用于排障。

  • 日志来自主进程 electron-log，按天滚动到 %APPDATA%\StockAnalyzer\logs\。
  • 页面每 30 秒自动刷新一次，最新日志显示在最上方。
  • 切到其他页面再回来时自动重新抓取最新内容。
  • 不可编辑日志内容。如需清理，请到上述目录手动删除旧文件。
注意 日志中可能含接口请求 / 错误堆栈，包含股票代码、价格等业务字段，但不含账号密码。如需将日志外发排查问题，请确认无隐私敏感信息。

15. 常见问题

15.1 添加自选股时显示"股票代码格式错误"

代码必须以 sh / sz / bj / hk 开头，后接 6 位数字。例如 sh600519、sz000001、hk00700。

15.2 看不到最新价格

可能原因：

  1. 当前不在交易时段——非交易时段不主动轮询。
  2. API 接口限流或临时不可达——到"日志"页面查看错误堆栈。
  3. 轮询间隔设得太大——到"设置"调小（注意不能小于 1 分钟）。
  4. 代理 / 防火墙拦截——检查系统代理。

15.3 自选股列表里的某只股票突然"最新价"为 0

通常是接口返回异常。该股票仍在数据库，不会丢。点击"刷新"或重启应用可恢复。

15.4 持仓里显示的"成本均价"和我记的不一致

StockAnalyzer 使用移动加权平均法计算成本。如果你的记录中有多次买入且包含卖出，请确认：

  • 所有买入都已录入。
  • 所有卖出的价格 / 数量都正确（成本会按"卖出对应成本 = 卖出价 × 数量"反向扣减）。

15.5 网格仿真显示"无 K 线数据"

请先在"自选股 → 下载K线"中下载该股票的日 K 数据，且 K 线根数 ≥ 20。日期窗口起点必须 ≤ 已下载的最早一天。

15.6 形态检测一直显示"暂无数据"

可能原因：

  • 所选股票未下载 K 线。
  • 已下载但 K 线根数 < 20。
  • 日期窗口内确实没有命中任何形态——可尝试切换到"全部"日期窗口或"全部方向"筛选。

15.7 资金明细里的"账户余额"算错了

账户余额由所有资金流水按时间正序滚动累加得到。检查：

  1. 是否漏录了某笔入金 / 出金。
  2. 某笔手工录入的金额符号是否填反（出金应填负数）。
  3. 是否手动删除了自动同步的资金流水——这会导致后续滚动计算基础值错位。

15.8 数据迁移到新电脑

  1. 在旧电脑的"设置 → 数据库备份"手动备份一次。
  2. 把 %APPDATA%\StockAnalyzer\stockanalyzer-YYYYMMDD-HHmmss.db 拷贝到新电脑。
  3. 在新电脑安装 StockAnalyzer，启动一次让它生成默认数据库，然后退出。
  4. 把备份文件改名为 stockanalyzer.db，覆盖到新电脑 %APPDATA%\StockAnalyzer\。
  5. 重新启动 StockAnalyzer，所有数据恢复。

15.9 应用启动失败 / 闪退

  1. 到"日志"页面查看最近一次错误（如果你能看到的话）。
  2. 把 %APPDATA%\StockAnalyzer\logs\ 下最新一天的日志文件发给开发者。
  3. 若无法启动，可尝试"安全模式"：删除 %APPDATA%\StockAnalyzer\stockanalyzer.db（会丢数据，请先备份）后重启。

16. 附录 · 术语表

术语 含义
自选股 用户主动加入监控列表的股票，可设买卖阈值、启停监控。
持仓 当前仍持有的股票及其数量与成本，由交易记录自动汇总，不可手动录入。
历史开仓 已清仓（买卖配对最终持仓为 0）的股票及其完整交易链。
网格交易 在价格区间内按固定间距布"买卖档"，每档触发即机械执行。
网格仿真 把网格/阈值策略在历史 K 线上回放一遍，输出模拟盈亏。
资金明细 所有影响账户余额的流水，包括手工录入与交易同步。
账户余额 资金流水中最后一条的 account_balance，由系统滚动计算。
持仓市值 所有当前持仓 最新收盘价 × 持仓数量 之和。
总资产 账户余额 + 持仓市值。
浮动盈亏 (最新价 - 成本均价) × 持仓数量，未实现。
已实现盈亏 已清仓周期的累计盈亏，已锁定。
移动加权平均 成本算法：avgCost = Σ(price × qty) / Σ(qty)，每次卖出按对应成本反向扣减。
前复权 (qfq) 以最近一次除权除息为基准，回溯调整历史价格，看趋势更连贯。
不复权 (none) 保留真实成交价，适合核对历史交易记录。
K 线 日级 OHLCV 行情数据（Open / High / Low / Close / Volume）。
形态识别 基于日 K 序列检测日本蜡烛图经典形态（看涨 / 看跌 / 转折预警）。
阈值全仓策略 仅用买入 / 卖出两个触发价做全仓 / 空仓切换的简化策略。
半仓平衡策略 按日收盘动态平衡，使持仓金额持续接近可用资金的 50%。
MACD / KDJ / MA 技术分析常见指标，本应用未内置计算公式，需自行引入第三方库或人工判断。
复权日 发生除权除息的交易日，会同时影响前复权与不复权数据。
涨跌停 A 股个股 ±10%（ST 股 ±5%、科创板 / 创业板 ±20% 等）的当日价格上下限，可能无法按仿真价成交。
T+1 A 股当日买入次日才可卖出。StockAnalyzer 在成本算法中已隐含此规则。
