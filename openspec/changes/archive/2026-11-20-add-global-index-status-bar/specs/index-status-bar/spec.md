## Purpose

在主内容区底部状态栏实时展示核心市场指数行情，使用户在任何功能页面都无需切换页面即可一屏掌握市场整体表现。本次变更将状态栏从自选股页面内提升为跨视图常驻的主内容区底栏，统一其与标题栏的视觉样式，并把数据异常提示收敛为栏内右侧的紧凑标签。

## MODIFIED Requirements

### Requirement: 数据异常降级

系统SHALL在指数数据获取失败时保留上次成功数据进行展示，同时在状态栏内部最右侧以紧凑标签显示错误提示；该标签 MUST NOT 遮挡任何指数项文字，也 MUST NOT 超出状态栏边界。

#### Scenario: 错误时保留上次数据
- **WHEN** 某次价格刷新中指数数据获取失败（`status` 为 `error`）
- **THEN** 状态栏继续显示上次成功获取的指数数据，指数内容保持可读

#### Scenario: 错误提示在栏内右侧紧凑显示
- **WHEN** 系统处于错误状态
- **THEN** 状态栏最右侧出现一个紧凑错误标签（文案为「数据更新失败」），标签垂直居中、高度不超过状态栏高度，三个指数项文字完整可见

#### Scenario: 恢复正常后提示消失
- **WHEN** 下一次价格刷新指数数据获取成功
- **THEN** 栏内错误标签消失，状态栏仅保留三个指数项

## ADDED Requirements

### Requirement: 状态栏跨视图常驻

系统SHALL在任意视图下渲染同一个指数状态栏，位置为主内容区（侧边导航栏右侧区域）的底部，宽度与主内容区一致、左边缘与主内容区对齐，且不跨越侧边导航栏；状态栏 MUST NOT 随页面内容滚动。

#### Scenario: 切换视图后状态栏仍可见
- **WHEN** 用户从自选股切换到持仓、网格、历史交易、资金管理、形态扫描、设置或日志等任意页面
- **THEN** 主内容区底部仍显示同一状态栏，指数数据与切换前一致，不出现重新订阅、重新加载或占位符闪烁

#### Scenario: 状态栏不随内容滚动
- **WHEN** 当前页面内容高度超过可视区域并向下滚动
- **THEN** 状态栏固定在主内容区底部不动，滚动仅发生在状态栏上方的页面区域内

#### Scenario: 状态栏左边缘对齐主内容区
- **WHEN** 应用窗口显示侧边导航栏
- **THEN** 状态栏左边缘与主内容区左边缘重合，不覆盖、不延伸到侧边导航栏下方

### Requirement: 状态栏视觉与标题栏一致

系统SHALL使用与标题栏相同的语义样式变量渲染状态栏外观：背景色 `--title-bar-bg`、上边分隔线 `1px solid --border-color`、指数名称文字 `--text-color`，MUST NOT 硬编码颜色值。

#### Scenario: 与标题栏视觉统一
- **WHEN** 状态栏渲染于主内容区底部
- **THEN** 其背景色与顶部标题栏一致、分隔线颜色与全局边框色一致，且样式通过 CSS 变量定义而非硬编码色值
